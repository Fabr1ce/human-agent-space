# Support

- **How-to questions:** Open a GitHub issue with the question and relevant
  command output. Remove credentials and private data first.
- **Bug reports:** Use the
  [bug report form](https://github.com/Fabr1ce/human-agent-space/issues/new?template=bug_report.yml).
- **Feature requests:** Use the
  [feature request form](https://github.com/Fabr1ce/human-agent-space/issues/new?template=feature_request.yml).
- **Security concerns:** Follow [SECURITY.md](SECURITY.md); do not report
  vulnerabilities in public issues.

HAS is maintained by volunteers. Please include the HAS version, Node.js
version, operating system, and a minimal reproduction when relevant.
