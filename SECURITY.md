# Security Policy

## Supported versions

Until versioned releases are available, security fixes are made on the
default branch. Once releases are published, the latest supported release will
receive security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately using
[GitHub's private vulnerability reporting](https://github.com/Fabr1ce/human-agent-space/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability. Include the
affected version or commit, impact, and steps to reproduce when safe to do so.

We will acknowledge reports and coordinate a fix and disclosure with the
reporter. Do not include real credentials or private user data in a report.
